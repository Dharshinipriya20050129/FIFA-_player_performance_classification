# FIFA-_player_performance_classification

This R mini project focuses on predicting whether a football player is "High Rated" or "Not High Rated" using machine learning classification techniques.

Two machine learning algorithms are used:

Decision Tree
Random Forest
The performance of both models is compared using Accuracy, F1-Score, Precision, and Recall. Feature importance is also analyzed to identify the most influential factors affecting player ratings.

Objectives

To predict whether a football player is High Rated or Not High Rated.
To implement a Decision Tree classification model.
To implement a Random Forest classification model.
To compare the performance of both machine learning models.
To identify the most important features affecting player ratings.
To evaluate the models using confusion matrices and performance metrics.
Dataset

The dataset contains football player attributes and rating-related information.

The target variable is divided into two classes:

High Rated
Not High Rated
Important features include:

Reactions
Potential
International Reputation
Ball Control
Standing Tackle
Short Passing
Composure
Positioning
Vision
Sliding Tackle
